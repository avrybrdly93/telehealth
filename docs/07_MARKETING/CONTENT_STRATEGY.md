# Content Strategy

## Purpose
Content earns trust and rankings by answering the questions patients actually have, at the depth a clinician would answer them, in plain language (COPY_GUIDELINES.md governs voice and hard rules; this doc governs what we publish).

## Content Types & Cadence

| Type | Purpose | Cadence | Review gate |
|---|---|---|---|
| Condition pages (/conditions/*) | SEO entry + education | 3 at launch; +1–2/month post-launch max | Provider review before publish (Tier 3, R-010) — hard gate |
| FAQ entries | Objection handling, long-tail queries | Add as real questions arrive (contact form themes) | Provider review for anything clinical |
| Service pages | Conversion | Stable; revised from funnel data | Tier 3 (pricing/clinical claims) |
| "Your first visit" & policy content | Anxiety reduction | Stable | Human review |

No blog in MVP. If founders want one later, it's a scope decision — condition pages deliver the SEO value with a tighter quality gate.

## Condition Page Standard (every page)
1. Plain-language "what it is / how it feels" (lived-experience framing, non-diagnostic).
2. "How psychiatric care typically helps" — treatment *categories* (evaluation, medication, coordination with therapy), never specific drug recommendations.
3. Educational disclaimer (COPY_GUIDELINES rule 2) + crisis note where relevant (esp. depression page).
4. Link to matching service + Book CTA + reviewed-by attribution when true.
5. 800–1,200 words; reading level ≤ 8th grade; sources cited to reputable clinical references where stats appear.

## Sourcing Rules
Statistics only from: NIMH, CDC, SAMHSA, APA, peer-reviewed sources — linked. No "studies show" without a link. Numbers rechecked at each review cycle.

## Content From Real Questions
Monthly: cluster contact-form and intake themes (from clinical ops, summarized without any patient details) → FAQ/content candidates → prioritized in BACKLOG.md.
