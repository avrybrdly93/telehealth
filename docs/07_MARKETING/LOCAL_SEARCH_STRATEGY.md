# Local Search Strategy

## Reality Check for a Telehealth-Only Practice
Local packs favor physical locations. As telehealth-only, we compete statewide, not on "near me" proximity. Strategy: statewide topical authority (SEO_STRATEGY.md) + clean profile hygiene, not local-pack chasing. Do NOT create fake city addresses or virtual-office listings — prohibited (trust + guideline violations).

## Profile Hygiene (human tasks, tracked in backlog when actionable)
- **Google Business Profile**: telehealth/service-area configuration per current Google policy for virtual providers; accurate categories (Psychiatrist / Mental health service), hours, booking link, both providers' names in description. Owner: founders.
- **NAP consistency**: one canonical practice name, phone, and (if any) registered address everywhere — site footer, GBP, directories. Canonical values live in practice.ts and are the only source for the site.
- **Provider directories** (high-authority citations + real referral sources): Psychology Today, CA medical board profiles accurate, NPI registry current, ZocDoc-type only if booking flow consistency is maintained.

## Site-Side Support (agent-actionable)
- schema.org MedicalBusiness with areaServed: California; no fake address markup.
- Footer license disclosure line ("Licensed in California") — FR-014 adjacency.
- /conditions and service pages mention California naturally (serving patients "throughout California — from San Diego to the Bay Area to the Central Valley") — once per page, not stuffed.

## Reviews
Ask only via clinical-ops process (never automated site prompts in MVP); respond to all reviews without confirming anyone is a patient (respond generically — acknowledging patienthood in a reply is a privacy violation). Review responses are a human task, never an agent task.

## Measurement
GBP insights (calls, booking clicks) monthly + branded-query impressions in Search Console; reported in CONTINUOUS_IMPROVEMENT loop.
